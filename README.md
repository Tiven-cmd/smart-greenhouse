Smart Greenhouse Monitoring System

Project Description
The Smart Greenhouse Monitoring System is a web-based system designed to monitor greenhouse conditions using sensors such as temperature, humidity, soil moisture, and light sensors.

Current Status
Status: In Development
The website is completed and ready. Currently, we are working on:
-Connecting the light sensor and lighting component.
-Connecting the real sensor readings to the website.
-Testing and finalizing the complete system.
-The project is still under development and integration.
